# أكاديمية المحترفين - منصة الكورسات الشاملة

موقع تعليمي تفاعلي مجاني بيجمع كل الكورسات في مكان واحد.

## 📚 الأقسام الموجودة في الموقع
- *جرافيك ديزاين*: Photoshop, Illustrator, InDesign من الصفر للاحتراف
- *البرمجة*: HTML, CSS, JavaScript, Python, C++, PHP, SQL
- *اللغات*: إنجليزي، إيطالي، فرنساوي، ألماني، إسباني
- *منصات خارجية*: روابط مباشرة لـ Udemy, Coursera, YouTube

## ✨ المميزات
- تصميم متجاوب يشتغل على الموبايل والكمبيوتر
- كويزات تفاعلية بتصح نفسها فوراً
- نظام تتبع التقدم والمفضلة
- Dark/Light Mode
- البحث والفلترة داخل الكورسات
- كل حاجة في ملف واحد index.html عشان يشتغل على GitHub Pages
